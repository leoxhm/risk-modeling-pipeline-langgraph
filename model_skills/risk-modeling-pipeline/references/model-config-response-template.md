# 模型配置确认摘要

> 只展示建模决策，不展开完整 YAML；训练效果和模型审查结果在训练完成后另行反馈。

| 类别 | 决策项 | 当前选择 | 说明 |
|---|---|---|---|
| 样本切分 | 时间划分 | `Train=早期月份；Validate=最近若干月；OOT=最新若干月` | 按时间顺序模拟上线，避免未来信息泄漏；OOT 只作最终验证 |
| 调参设置 | 调参方式 | `LLM / Optuna / 仅 Baseline` | 三种方式互斥，本次只执行一种 |
| 模型选择 | 基础模型 | `LightGBM` | 当前版本仅支持 LightGBM |

完整参数仅由引擎在工作区内部读取、校验和复现，不在聊天区展开。
