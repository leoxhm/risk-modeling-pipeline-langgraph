# EDA 节点回复模板

EDA 的完整指标和图表保存在 HTML、Excel、CSV 文件中；聊天窗口不重复展示 EDA 明细，
节点完成后自动进入样本诊断。必要时只提示报告路径。

```markdown
## EDA分析完成（报告已生成）

已分析 {行数} 条样本和 {特征数} 个特征，报告已生成；未进行样本切分、字段删除或模型训练。

完整图表：{html_report_path}

系统将自动进入已选的样本诊断节点；完整指标和图表请查看报告。
```

要求：所有数值必须来自 `eda_summary.json`、`node_summary.json` 或报告明细，不得自行估算；告警使用“需关注”，不写“阻断”。
